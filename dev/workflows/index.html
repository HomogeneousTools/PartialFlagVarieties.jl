Common Workflows

This page organizes the package by task rather than by module name.

Construct an arbitrary partial flag variety

Use a named constructor when one exists:

X = Gr(2, 5)
Y = quadric(5)
Z = cayley_plane()

Otherwise use partial_flag_variety:

X = partial_flag_variety("D5", [2, 5])
marked_dynkin_diagram(X)

The quickest structural invariants are:

dimension(X)
euler_characteristic(X)
betti_numbers(X)
picard_rank(X)

Compute cohomology of an equivariant bundle

The usual pattern is:

X = Gr(2, 5)
E = exterior_power(tangent_bundle(X), 2)

H = dimensions(E)
H[0]
chi(H)

Use cohomology(E) when you want the full ambient representation in each cohomology group, and dimensions(E) when only the dimensions matter.

Build standard bundles

The public bundle interface is meant to cover most use cases:

X = Gr(2, 5)
U = universal_subbundle(X)
Q = universal_quotient_bundle(X)

E = twist(exterior_power(Q, 2), 1)
F = direct_sum(E, canonical_bundle(X))

For multi-step type-A flags, tautological_bundles and quotient_bundles are best thought of as convenient equivariant building blocks, not literal geometric tautological flags.

Study a zero locus

X = Gr(2, 5)
E = line_bundle(X, 1)
Z = zero_locus(E)

codimension(Z)
normal_bundle(Z)
koszul_terms(Z)
cohomology_on_restriction(Z, tangent_bundle(X))

This is the right workflow when you want cohomology of restrictions, Euler characteristics, Hodge numbers, or Fano / Calabi–Yau tests for $Z$.

Interpret symbolic Hodge output

For higher-codimension zero loci, the long exact sequences may leave genuinely undetermined connecting-map ranks. In that case the package returns AffineExpr entries:

X = Gr(2, 7)
S = universal_subbundle(X)
E = direct_sum(symmetric_power(dual(S), 2), symmetric_power(dual(S), 2))
Z = zero_locus(E)
H = hodge_numbers_symbolic(Z)

Use is_determined to test whether an entry is numerical or still contains a symbolic variable.

Round-trip external labels

If you work with datasets or published classifications that use ZeroLocus62 labels, the package can encode and decode them:

label = zerolocus62_label(Gr(2, 4))
X = PartialFlagVariety(label)

See Labels for the precise conventions and caveats.
