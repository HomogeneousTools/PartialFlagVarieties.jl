IrrepLevi

Irreducible representations of the Levi subgroup $L$ of the parabolic $P \subseteq G$.

Mathematical background

The Levi factor of a parabolic subgroup decomposes as $L = \operatorname{Z}(L)^\circ \cdot [L,L]$, where $\operatorname{Z}(L)^\circ$ is the connected center (a torus of rank equal to the number of marked nodes $|I|$) and $[L,L]$ is the semisimple part (whose Dynkin diagram is the sub-diagram on the unmarked nodes).

Every irreducible $L$-representation therefore splits as

\[V = \chi \otimes W\]

where $\chi$ is a character of the center $\operatorname{Z}(L)^\circ$ and $W$ is an irreducible representation of $[L,L]$ with highest weight $\mu$.

An IrrepLevi stores this decomposition: the central part is a vector of integers (the character coordinates times the central_scaling_factor), and the semisimple part is a WeightLatticeElem for $[L,L]$.

Design notes

Why `IrrepLevi` is an internal type

Users construct equivariant bundles via the public API: line_bundle, tangent_bundle, exterior_power, etc. These functions build CompletelyReducibleBundle objects whose internal decomposition into IrrepLevi components happens automatically.

The situations where a user encounters IrrepLevi directly are:

  • Inspecting components(E) to see the irreducible summands of a bundle
  • Advanced computations that need the central/semisimple coordinates
Caching of tensor products

Tensor products of IrrepLevi decompose via Lie.jl character arithmetic, which involves computing tensor product branching rules from Weyl character data. This is the hottest path in the package and is LRU-cached: see PartialFlagVarieties.configure_caches! for tuning the cache budget.

Type

PartialFlagVarieties.IrrepLevi — Type
IrrepLevi(mdt::MarkedDynkinType, λ::WeightLatticeElem)

An irreducible representation of the Levi factor attached to mdt, stored by its ambient $P$-dominant weight together with its central and semisimple Levi

Examples

julia> using PartialFlagVarieties, Lie

julia> X = Gr(3, 6);

julia> rep = IrrepLevi(marked_dynkin_type(X), [0, 1, -1, 0, 0]);

julia> rep == only(components(universal_subbundle(X)))
true

julia> semisimple_part(rep)
ω2

julia> fiber_dimension(rep)
3

coordinates.

PartialFlagVarieties.p_dominant_weight — Function
p_dominant_weight(rep::IrrepLevi) -> WeightLatticeElem

Return the ambient $P$-dominant weight $\lambda$ of the irreducible Levi representation rep. This is the weight of $G$ in fundamental weight coordinates from which the central and semisimple parts were derived via the decomposition matrix.

PartialFlagVarieties.fiber_dimension — Function
fiber_dimension(rep::IrrepLevi) -> Int

Return the dimension of the fiber of the equivariant bundle defined by rep, i.e., the dimension of the irreducible representation of the semisimple Levi factor given by the Weyl dimension formula.

PartialFlagVarieties.to_ambient_weight — Function
to_ambient_weight(rep::IrrepLevi) -> WeightLatticeElem

Return the ambient P-dominant weight of rep in the fundamental weight basis of the ambient Lie algebra.
