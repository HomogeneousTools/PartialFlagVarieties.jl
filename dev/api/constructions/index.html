Constructions

Named convenience constructors for classical and exceptional varieties.

Type A

PartialFlagVarieties.Gr — Function
Gr(k, n) -> PartialFlagVariety

The Grassmannian $\mathrm{Gr}(k, n)$ of $k$-planes in $\mathbb{C}^n$.

It is the generalized Grassmannian $\mathrm{A}_{n-1}/\mathrm{P}_k$, encoded by marking node $k$ in the Dynkin diagram of type $\mathrm{A}_{n-1}$.

Examples

julia> using PartialFlagVarieties

julia> V = Gr(2, 5);

julia> dimension(V)
6

julia> euler_characteristic(V)
10
PartialFlagVarieties.grassmannian — Function
grassmannian(k::Integer, n::Integer) -> PartialFlagVariety

The Grassmannian $\mathrm{Gr}(k, n)$ of $k$-dimensional subspaces of an $n$-dimensional vector space; a spelled-out synonym of Gr.

Examples

julia> using PartialFlagVarieties

julia> grassmannian(2, 5) == Gr(2, 5)
true

PartialFlagVarieties.flag_variety — Function
flag_variety(n, dimensions) -> PartialFlagVariety

The type-$A$ partial flag variety $\mathrm{Fl}(d_1, \ldots, d_r; n) = \mathrm{A}_{n-1}/\mathrm{P}_{\{d_1,\ldots,d_r\}}$.

Here dimensions = (d_1, ..., d_r) are the dimensions of the subspaces in the partial flag $0 \subsetneq V_{d_1} \subsetneq \cdots \subsetneq V_{d_r} \subsetneq \mathbb{C}^n$; they must be distinct, sorted in increasing order, and satisfy $1 \leq d_i \leq n-1$.

Examples

julia> using PartialFlagVarieties

julia> V = flag_variety(4, [1, 2]);

julia> dimension(V)
5

Types B and D (orthogonal)

PartialFlagVarieties.OGr — Function
OGr(k, n) -> PartialFlagVariety

The orthogonal Grassmannian $\mathrm{OGr}(k, n)$ of isotropic $k$-planes in $\mathbb{C}^n$ with a symmetric bilinear form.

For $n = 2m + 1$ (odd): type $\mathrm{B}_m$, mark node $k$. For $n = 2m$ (even) and $k < m$: type $\mathrm{D}_m$, mark node $k$. For $n = 2m$ and $k = m$: this is the spinor variety $\mathrm{OGr}_+(m, 2m)$, type $\mathrm{D}_m$ mark node $m$.

When $n = 2m$ and $k = m$, the maximal orthogonal Grassmannian has two connected components. OGr(m, 2m) picks the component corresponding to node $m$; the other component is $\mathrm{D}_m/\mathrm{P}_{m-1}$.

Examples

julia> using PartialFlagVarieties

julia> V = OGr(5, 10);  # spinor variety S₅

julia> dimension(V)
10

julia> euler_characteristic(V)
16
PartialFlagVarieties.IGr — Function
IGr(k, n) -> PartialFlagVariety

Synonym for OGr, used to emphasize that the planes are isotropic for an orthogonal form.

PartialFlagVarieties.quadric — Function
quadric(n) -> PartialFlagVariety

The smooth quadric hypersurface $Q_n \subset \mathbb{P}^{n+1}$.

For odd $n = 2m - 1$: $\mathrm{OGr}(1, 2m + 1)$ = $\mathrm{B}_m / \mathrm{P}_1$. For even $n = 2m - 2$: $\mathrm{OGr}(1, 2m)$ = $\mathrm{D}_m / \mathrm{P}_1$.

Equivalently, quadric(n) is the isotropic-line Grassmannian $\mathrm{OGr}(1, n+2)$.

Examples

julia> using PartialFlagVarieties

julia> V = quadric(4);

julia> dimension(V)
4

julia> betti_numbers(V)
5-element Vector{BigInt}:
 1
 1
 2
 1
 1

Type C (symplectic)

PartialFlagVarieties.SGr — Function
SGr(k, n) -> PartialFlagVariety

The symplectic Grassmannian $\mathrm{SGr}(k, n)$ of isotropic $k$-planes in $\mathbb{C}^n$ with a skew-symmetric form ($n$ must be even).

Type $\mathrm{C}_{n/2}$, mark node $k$.

Examples

julia> using PartialFlagVarieties

julia> V = SGr(2, 6);

julia> dimension(V)
7
PartialFlagVarieties.LGr — Function
LGr(n, 2n) -> PartialFlagVariety

The Lagrangian Grassmannian $\mathrm{LGr}(n, 2n) = \mathrm{SGr}(n, 2n)$ of Lagrangian (maximal isotropic) $n$-planes in a $2n$-dimensional symplectic space. The second argument must equal $2n$.

Examples

julia> using PartialFlagVarieties

julia> V = LGr(3, 6);

julia> dimension(V)
6

PartialFlagVarieties.adjoint_variety — Function
adjoint_variety(::Type{DT}) -> PartialFlagVariety

The adjoint variety of a simple Dynkin type DT, i.e. the projectivisation of the minimal nilpotent orbit.

The marked node is the adjoint node, determined by the highest root of DT.

Examples

julia> using PartialFlagVarieties

julia> V = adjoint_variety(TypeE{6});

julia> dimension(V)
21
PartialFlagVarieties.coadjoint_variety — Function
coadjoint_variety(::Type{DT}) -> PartialFlagVariety

The coadjoint variety of a simple Dynkin type DT.

For simply laced types it agrees with the adjoint variety. For nonsimply laced types it is determined by the highest short root.

Examples

julia> using PartialFlagVarieties

julia> V = coadjoint_variety(TypeG2);

julia> dimension(V)
5
