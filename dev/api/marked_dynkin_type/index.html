MarkedDynkinType

The core type encoding a partial flag variety $G/P_I$ and the Levi factor of the parabolic subgroup $P_I$.

A MarkedDynkinType stores the ambient Dynkin type of $G$ together with a set of marked nodes $I \subseteq \{1, \ldots, r\}$ that specify the parabolic $P_I$. Structural invariants — the Levi type, decomposition matrix, root data, dimension, Euler characteristic, Betti numbers — are computed on demand and cached per marked Dynkin type.

Type

PartialFlagVarieties.MarkedDynkinType — Type
MarkedDynkinType(DT::Type{<:DynkinType}, marked)

Runtime description of a partial flag variety $G/P$, given by a Dynkin type DT and the tuple of marked simple roots defining the parabolic subgroup $P$.

The marked nodes are stored as runtime data rather than type parameters, while derived invariants such as the Levi type, decomposition matrix, and dimension are cached on first use.

Examples

julia> using PartialFlagVarieties, Lie

julia> mdt = MarkedDynkinType(TypeA{4}, (2,));

julia> marked_nodes(mdt)
(2,)

julia> unmarked_nodes(mdt)
(1, 3, 4)

Accessors

PartialFlagVarieties.dynkin_type — Function
dynkin_type(mdt::MarkedDynkinType) -> Type{<:DynkinType}

Return the ambient Dynkin type of mdt (e.g. TypeA{4} for $\mathrm{A}_4$).

PartialFlagVarieties.marked_nodes — Function
marked_nodes(mdt::MarkedDynkinType) -> Tuple{Vararg{Int}}

Return the tuple of marked simple root indices defining the parabolic subgroup $P$. In the convention used by this package, marked nodes are the crossed-out nodes of the Dynkin diagram: the parabolic $P_I$ is generated by $B$ and $U_{-\alpha_j}$ for $j \notin I$.

PartialFlagVarieties.unmarked_nodes — Function
unmarked_nodes(mdt::MarkedDynkinType) -> Tuple{Vararg{Int}}

Return the complement of marked_nodes, i.e. the simple root indices that span the Dynkin diagram of the semisimple Levi factor $[L, L]$. These are the uncrossed nodes.

PartialFlagVarieties.central_rank — Function
central_rank(mdt::MarkedDynkinType) -> Int

Return the rank of the center $\operatorname{Z}(L)^\circ$ of the Levi factor, equal to the number of marked nodes $|I|$. This also equals the Picard rank $\mathrm{rk}\,\mathrm{Pic}(G/P_I)$.

PartialFlagVarieties.levi_rank — Function
levi_rank(mdt::MarkedDynkinType) -> Int

Return the rank of the semisimple Levi factor $[L, L]$, i.e. the number of unmarked nodes.

PartialFlagVarieties.levi_type — Function
levi_type(mdt::MarkedDynkinType) -> Union{Nothing, Type{<:DynkinType}}

Return the Dynkin type of the semisimple part $[L, L]$ of the Levi factor, or nothing when all nodes are marked (the full flag variety $G/B$, where $L = T$ is a maximal torus and $[L, L]$ is trivial).

PartialFlagVarieties.is_borel — Function
is_borel(mdt::MarkedDynkinType) -> Bool

Return true if mdt encodes a full flag variety $G/B$ (all nodes marked, so $P = B$ is the Borel subgroup).

Decomposition matrix

The decomposition matrix $M$ performs the change of basis from the fundamental weight coordinates of $G$ to the (center + semisimple) coordinate system of the Levi factor $L = \operatorname{Z}(L)^\circ \cdot [L, L]$. Concretely, for the marked nodes $I$ the matrix $M$ has $|I|$ rows from the inverse Cartan matrix $C^{-1}$ and identity rows for the unmarked nodes, after reordering via levi_permutation.

PartialFlagVarieties.decomposition_matrix — Function
decomposition_matrix(mdt::MarkedDynkinType) -> Matrix{Rational{Int}}

Return the change-of-basis matrix from ambient fundamental weights to central-plus-Levi coordinates. Unmarked rows are the identity and marked rows are the corresponding rows of the inverse Cartan matrix.

PartialFlagVarieties.decomposition_matrix_inv — Function
decomposition_matrix_inv(mdt::MarkedDynkinType) -> Matrix{Rational{Int}}

Return the inverse of the decomposition_matrix, converting from central-plus-Levi coordinates back to ambient fundamental weight coordinates.

PartialFlagVarieties.central_scaling_factor — Function
central_scaling_factor(mdt::MarkedDynkinType) -> Int

Return the positive integer that clears all denominators in the marked rows of the decomposition_matrix. This is the LCM of the denominators of the entries $C^{-1}_{jk}$ for $j \in I$ (marked nodes) and all $k$.

Used internally to work with integer-scaled central characters instead of rationals.

PartialFlagVarieties.levi_permutation — Function
levi_permutation(mdt::MarkedDynkinType) -> Tuple{Vararg{Int}}

Return the permutation that sends the natural ordering of the unmarked nodes to the canonical Bourbaki ordering of the sub-Cartan matrix of $[L, L]$.

This is the identity for types $\mathrm{A}$, $\mathrm{B}$, and $\mathrm{C}$, but is nontrivial for types $\mathrm{D}$ and $\mathrm{E}$ where the sub-diagram nodes may not appear in canonical order within the ambient diagram.

Roots

PartialFlagVarieties.positive_nonparabolic_roots — Function
positive_nonparabolic_roots(mdt::MarkedDynkinType) -> Vector

Return all positive roots of the ambient Lie algebra that have positive coefficient on at least one marked simple root (i.e., the roots not in the Levi subalgebra). These span the tangent directions of $G/P$.

PartialFlagVarieties.positive_parabolic_roots — Function
positive_parabolic_roots(mdt::MarkedDynkinType) -> Vector

Return all positive roots of the ambient Lie algebra that have zero coefficient on every marked simple root (i.e., the positive roots of the Levi subalgebra).

PartialFlagVarieties.tangent_weights — Function
tangent_weights(mdt::MarkedDynkinType) -> Vector{WeightLatticeElem}

Return the highest weights of the irreducible Levi-module decomposition of the tangent space $T_{eP}(G/P)$ at the base point. Each weight corresponds to a Levi-orbit of nonparabolic positive roots.

Display

PartialFlagVarieties.marked_dynkin_diagram — Function
marked_dynkin_diagram(mdt::MarkedDynkinType) -> String

Return an ASCII art string representation of the Dynkin diagram of mdt with the marked nodes highlighted (enclosed in square brackets).

Lie.jl utilities

Convenience functions for working with Dynkin types, built on top of Lie.jl.

PartialFlagVarieties.parse_dynkin_type — Function
parse_dynkin_type(s::AbstractString) -> Type{<:DynkinType}

Parse a string representation of a Dynkin type.

Components are separated by x or ×. Each component is a letter (A–G) followed by an integer rank.

Examples

julia> parse_dynkin_type("A3")
TypeA{3}

julia> parse_dynkin_type("A2xB3")
ProductDynkinType{Tuple{TypeA{2}, TypeB{3}}}

julia> parse_dynkin_type("E6")
TypeE{6}
PartialFlagVarieties.cartan_type — Function
cartan_type(C::AbstractMatrix{<:Integer}) -> Vector{Tuple{Symbol, Int}}

Return the Cartan type of a Cartan matrix C as a vector of (family, rank) pairs.

Examples

julia> cartan_type([2 -1; -1 2])
[(:A, 2)]

julia> cartan_type([2 -1 0 0; -1 2 0 0; 0 0 2 -1; 0 0 -2 2])
[(:A, 2), (:B, 2)]
PartialFlagVarieties.cartan_type_with_ordering — Function
cartan_type_with_ordering(C::AbstractMatrix{<:Integer}) -> Vector{Tuple{Symbol, Int}}, Vector{Int}

Given a Cartan matrix C, return a vector of (family, rank) pairs describing its Dynkin type, together with a permutation vector ord giving a canonical ordering of the rows/columns.

The algorithm decomposes the matrix into connected components via adjacency, then classifies each component by its graph structure (path vs branching, edge multiplicities).

Follows the same approach as OSCAR.jl's cartan_type_with_ordering.

Examples

julia> cartan_type_with_ordering([2 -1; -1 2])
([(:A, 2)], [1, 2])

julia> cartan_type_with_ordering([2 -1; -2 2])
([(:B, 2)], [1, 2])
